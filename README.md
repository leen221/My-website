# Leen Thaher — Portfolio Website

Personal portfolio website built with vanilla HTML, CSS, and JavaScript.  
Live at: [my-website-sigma-sand.vercel.app](https://my-website-sigma-sand.vercel.app/)

---

## Pages

| Page | Description |
|------|-------------|
| Home | Hero section with intro and profile |
| About | Background and personal summary |
| Experience | Work and volunteering history |
| Skills | Technical and soft skills |
| Certificates | Completed courses and certifications |
| Projects | ML, NLP, and optimization projects |
| Goals | Future ambitions |
| Contact | Contact form and links |

---

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- Google Fonts (Syne, DM Sans)
- Deployed on Vercel

---

## Run Locally

No install needed. Just open `index.html` in your browser,  
or use Live Server in VS Code.
